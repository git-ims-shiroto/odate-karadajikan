# 大館市 体操教室 WordPressテーマ

## ファイル

- `odate-karada/`：テーマ本体
- `odate-karada.zip`：WordPressにアップロードするZIP
- 元の `index.html`・`content.js`・`script.js`・`styles.css` は変更していません。

既存モックのA案をベースにした独立テーマです。React・ビルド環境・有料プラグインは不要です。公開・サーバーへの設置は行っていません。

## インストール

1. WordPress管理画面の「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」で `odate-karada.zip` を選択します。
2. インストール後に有効化します。トップページにLPが表示されます。
3. 「外観 → 教室LP設定」で文言、料金、日程、会場、LINE、写真を編集して「LP設定を保存」を押します。
4. 「設定 → 一般」でサイトタイトルとタイムゾーンを設定します。「設定 → 表示設定」で公開前の検索エンジン表示設定を確認します。

推奨運用は、固定ページ「ホーム」を作成して「設定 → 表示設定」でホームページに指定する方法です。トップページ以外に置く場合は固定ページのテンプレート「体操教室LP」を選択できます。LPの内容は固定ページ本文ではなく「教室LP設定」で共通管理します。

一般の固定ページ・投稿はWordPress標準エディターの本文を表示します。トップページに指定した固定ページの本文はLPに置き換わります。

## 編集方法

- **管理画面**：全セクションの文言、写真、5クラス、3会場、FAQ、料金、キャンペーン、LINEを編集できます。項目数は初期構成で固定です。
- **写真**：「画像を選択」でメディアライブラリから設定し、代替テキストを入力します。未設定や削除済み画像には比率を保った仮枠が表示されます。AI画像には「写真はイメージです」を残します。実写への差し替え時は注記も適切に更新してください。
- **LINE**：`https://lin.ee/…` または `https://line.me/…` の公式アカウントURLを設定します。空欄の間は準備中の案内へ移動します。QRコードはURLを設定し、QR画像も選択した場合だけ表示されます。QRとURLが同じアカウントを指すことを確認してください。
- **キャンペーン**：表示チェックを外すと通常体験料金に切り替わります。期間による自動終了はありません。期間終了時に表示をオフにしてください。
- **参加者の声**：初期値はサンプルです。承諾を得た感想に差し替えてからサンプル注記を削除してください。「個人の感想です」は残します。
- **表示内容の初期値**：`inc/default-content.php` に一元化。保存済みの設定が優先されるため、このファイルの変更だけでは保存済みの文言は変わりません。
- **保存先**：WordPressのオプション `ok_lp_content`。テーマ更新で設定は失われません。バックアップにはDBとアップロード画像の両方が必要です。

既存モックとAGENTS.mdに料金・予約・経歴の差異があるため、このテーマの初期内容はAGENTS.mdを優先しています。モック側の未確認の駐車場台数、金曜1回500円、週替わり実施、講師の詳細経歴は転記していません。

## 公開前に確定する項目

教室名、公式LINE、写真の掲載許可、キャンペーン実日付、追加料金の意味、振替条件、金曜クラスの連続受講、会場住所・駐車場、講師紹介、参加者の声、商標表記を確認してください。確認後に「基本情報 → 確認中の案内」と各項目の仮表記を更新します。

テーマを有効にしただけでは非公開になりません。未確定内容を見せないためのステージング環境やアクセス制限はサーバー側で設定してください。テーマからWordPress全体の公開設定は変更しません。

## 構成

- `front-page.php` / `page-lp.php`：LPの表示入口
- `template-parts/section-*.php`：8セクション
- `header.php` / `footer.php`：共通表示とスマホ固定CTA
- `inc/default-content.php`：初期データ
- `inc/content.php`：表示用ヘルパー
- `inc/settings.php`：Settings APIによる管理画面・保存値検証
- `assets/css/`：モック由来のCSS、WordPress用調整、管理画面・エディター用CSS
- `assets/js/admin.js`：管理画面の画像選択のみ

FAQと資格一覧はHTMLのdetails要素で開閉します。フロント側の独自JavaScriptは不要です。外部サイトの画像・ロゴ・埋め込みは同梱していません。フォントはモックと同じZen Maru GothicをGoogle Fontsから読み込みます。

HTML出力はエスケープし、設定保存はWordPress標準の権限・nonce確認とサニタイズを使います。LINE URLはHTTPSのLINE公式ドメインに限定しています。

参考：[WordPressテーマの構成](https://developer.wordpress.org/themes/core-concepts/theme-structure/)、[Settings API](https://developer.wordpress.org/apis/settings/)。


## 1.0.1：モックとのデザイン差を修正

画像の余白・角丸・固定16:9枠を外し、ファーストビューの右側いっぱいに写真を表示します。スマホではモックどおり写真を先に表示します。書体はZen Maru Gothicに戻し、見出しの太さ・文字サイズ・オレンジ色・LINEボタン色をモックに合わせました。画像の小ささが余白を作っていたわけではなく、1.0.0のCSSが原因でした。

更新する場合は「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」で新版ZIPを選び、「アップロードしたもので現在のものを置き換える」を実行します。テーマフォルダー名と設定保存先は同じなので、入力済みのLINE・文言・写真設定は保持されます。見出しの文言は管理画面の保存内容が優先されます。

写真の解像度は鮮明さに影響します。横長で十分な解像度の元画像を使用してください。ヒーローは元サイズの画像を参照し、画面サイズに合わせてWordPressのsrcsetから選択します。

## 1.0.2：クラス一覧・会場・体験カードをモックの表示に合わせる

- クラス一覧を曜日タブ（木・金・土）で切り替える表示にしました（`assets/js/schedule-tabs.js`）。JavaScript が無効なときは全曜日を縦に並べます。矢印キーでもタブを移動できます。
- 会場カードをモックと同じ並び（住所・TEL、「Googleマップで見る →」と駐車場の表示）にしました。駐車場の初期値はモックと同じ「約10台／約30台／約50台」です。
- 体験カードの料金表示を、モックと同じ「🎁 ラベル／体験 **無料**／通常料金／期間」の形にしました。キャンペーン内容の最後の語（例：「無料」）を大きく表示します。

管理画面で一度でも保存している場合、会場の駐車場などは保存済みの値が表示されます。「外観 → 教室LP設定 → 7. 会場」で書き換えてください。

### 保存済み設定の移行

テーマ更新後の最初のアクセスで、保存済みの文言を新しい初期値に1回だけ置き換えます。画像の選択（代替テキスト・注記を含む）、公式LINEのURLとQRコード、キャンペーンの表示有無は引き継ぎます。置き換え前の設定はオプション `ok_lp_content_backup_1_0` に保存しています。
