# 画像差し替え一覧

このモックでは `sample-assets/` 内の提供素材を仮使用しています。本番制作時は、下記ファイル名で撮影写真または使用許諾を確認した画像へ差し替える想定です。

| ファイル名 | 推奨比率 | 内容 | 備考 |
|---|---:|---|---|
| `hero.jpg` | 16:9 | 立位・マット運動など、教室全体の内容が伝わる自然で明るい風景 | 椅子やひめトレだけを主役にしない。参加者の許諾が必要 |
| `lesson-main.jpg` | 3:2 | 立つ・座る・マット運動が伝わる少人数の教室風景 | 参加者の許諾が必要 |
| `instructor.jpg` | 1:1 | 松田聖子さんの写真 | 顔が特定できる写真は掲載可否を確認 |
| `lesson-himetore.jpg` | 4:3 | ひめトレポールを使う様子 | 商標表記ルールを確認 |
| `lesson-self-conditioning.jpg` | 4:3 | セルフコンディショニングの様子 |  |
| `lesson-recreation.jpg` | 4:3 | レクリエーション体操の様子 |  |
| `tool-himetore.jpg` | 4:3 | ひめトレポール |  |

AI生成画像を本番でも使用する場合は、画像の近くに「写真はイメージです」と明記します。実在する参加者の写真に見える使い方は避けます。

- `leaf.webp`（420×816・背景透過）：背景に散らす水彩の葉の装飾。テーマの `wordpress/odate-karada/assets/images/leaf.webp` も同じ画像。生成AI画像から背景のもやを除いて切り抜いたもの。
